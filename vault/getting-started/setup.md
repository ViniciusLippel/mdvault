# Setup

## Running the server

```bash
node server.js
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## Vault location

All notes are stored as plain `.md` files inside the `vault/` directory. You can edit them directly with any text editor — changes will appear in mdvault on the next file open.

## Folder structure

```
vault/
  welcome.md
  getting-started/
    setup.md
  projects/
    ideas.md
```

Folders can be nested to any depth.
